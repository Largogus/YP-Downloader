## Возможности

* Скачивание видео по ссылке
* Выбор качества видео
* Автоматический выбор лучшего доступного качества
* Объединение видео и аудио через FFmpeg
* Поддержка прокси (Пока-что только встроенный)
* Удобный графический интерфейс

## Возможные ограничения и сетевые ошибки

Стабильность работы приложения зависит от доступности удаленных серверов и качества интернет-соединения. Возможные сбои при работе:

* Ошибки подключения к серверу или недоступность выбранного прокси-узла.
* Превышение времени ожидания ответа (таймаут) при высокой нагрузке на сеть.
* Изменение структуры метаданных на стороне видеохостинга.
